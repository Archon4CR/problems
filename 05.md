### Problem 7

Prove that the clique problem is NP-complete.

*Hint:* Show that 3SAT is polynomial-time reducible to the Clique problem.

* **The Clique Problem:** Given a graph $G$, the clique problem asks to find the largest clique in $G$ (a clique of order $k$ is a complete graph on $k$ vertices).


* **Decision Version:** Given a graph $G$ and an integer $k$, is there a clique of size at least $k$ in $G$?

### Problem 8

Prove that the Vertex Cover problem is polynomial-time reducible to the Dominating Set problem.

*Hint:* Replace every edge $(u, v)$ in $G$ with a triangle $(u, v, w)$ to form $G'$, where $w \in G'$ and $w \notin G$ (see Figure 1).

* **The Vertex Cover Problem:** Given a graph $G$ and a number $k$, the decision version of the vertex cover problem asks if there is a subset of size at most $k$ in $V(G)$ that covers all edges (i.e., every edge in $G$ intersects the subset).


* **Dominating Set Problem:** Given a graph $G(V, E)$ and a number $k$, the decision version asks if there is a dominating set of size $k$ in $V(G)$. A dominating set is a subset $A \subseteq V$ such that each vertex is either in $A$ or has a neighbor in $A$.

### Problem 10

Prove that the Subset Sum problem is NP-complete.

* **Subset Sum Problem:** Given a set $A$ of integers and an integer $k$, does there exist a subset of $A$ such that the sum of its elements is equal to $k$?

### Problem 11

Prove that the Hamiltonian cycle problem is NP-complete.

* **Hamiltonian Cycle Problem:** Given a graph $G$ on $n$ vertices, is there a cycle on $n$ vertices in the graph?



---

### Problem 12

Prove that the Hamiltonian Path problem is NP-Complete.

* **Hamiltonian Path Problem:** Given a graph $G$, does $G$ contain a path that visits every node exactly once?



*Hint:* Prove that the Hamiltonian Cycle problem is polynomial-time reducible to the Hamiltonian Path problem. Pick any edge $(u, v)$ in $G$, add two new vertices $u_1, v_1$ such that $u_1$ is only connected to $u$ and $v_1$ is only connected to $v$.

* **Decision Version:** Given an integer $k$, is there an $s-t$ path of length at least $k$ in $G$?
