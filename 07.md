## 1. Short Answers (25 points)

The questions below are of the type "true or false"; briefly justify your answer.

> **Note:** You may use any result shown in class or in homework without proving it. You may use the fact that you know particular problems are polynomial-time solvable or NP-complete.

1. **For all problems $X \in \mathcal{NP}$, $X \le_P \text{3D-MATCHING}$.**
   * **Answer:** **[TRUE]**
   * **Justification:** $\text{3D-MATCHING}$ is NP-complete, which by definition means it is NP-hard. Thus, every problem in $\mathcal{NP}$ polynomial-time reduces to it.

2. **If $\text{VERTEX-COVER} \in \mathcal{P}$, then $\text{SAT} \in \mathcal{P}$.**
   * **Answer:** **[TRUE]**
   * **Justification:** Since $\text{VERTEX-COVER}$ is NP-complete, any problem in $\mathcal{NP}$ polytime reduces to it, in particular $\text{SAT}$. From $\text{SAT} \le_P \text{VERTEX-COVER}$ and $\text{VERTEX-COVER} \in \mathcal{P}$, it follows that $\text{SAT} \in \mathcal{P}$.

3. **If $\mathcal{P} = \mathcal{NP}$, then $\text{SHORTEST-PATH}$ is NP-complete.**
   * **Answer:** **[TRUE]**
   * **Justification:** Any problem in $\mathcal{P}$ is polynomial-time reducible to any other non-trivial problem in $\mathcal{P}$. If $\mathcal{P} = \mathcal{NP}$, then the same holds for $\mathcal{NP}$. Since $\text{SHORTEST-PATH} \in \mathcal{NP}$, it follows that for all $X \in \mathcal{NP}$, $X \le_P \text{SHORTEST-PATH}$. Therefore, $\text{SHORTEST-PATH}$ is NP-complete.

4. **It is possible that $\text{INDEPENDENT-SET} \in \mathcal{P}$ and $\text{HAM-CYCLE} \notin \mathcal{P}$.**
   * **Answer:** **[FALSE]**
   * **Justification:** Since $\text{INDEPENDENT-SET}$ is NP-complete, any problem in $\mathcal{NP}$ polytime reduces to it, in particular $\text{HAM-CYCLE}$. From $\text{HAM-CYCLE} \le_P \text{INDEPENDENT-SET}$ and $\text{INDEPENDENT-SET} \in \mathcal{P}$, it follows that $\text{HAM-CYCLE} \in \mathcal{P}$, which contradicts $\text{HAM-CYCLE} \notin \mathcal{P}$.

5. **Let $X_1$ and $X_2$ be decision problems in $\mathcal{NP}$ and assume $\mathcal{P} \neq \mathcal{NP}$. If $X_1 \le_P X_2$ and $X_2 \le_P X_1$, then both $X_1$ and $X_2$ are NP-complete.**
   * **Answer:** **[FALSE]**
   * **Justification:** We give a counterexample. Take $X_1$ and $X_2$ to be non-trivial decision problems in $\mathcal{P}$. This implies $X_1 \le_P X_2$ and $X_2 \le_P X_1$. In addition, since $\mathcal{P} \neq \mathcal{NP}$ by assumption, $X_1$ and $X_2$ are not NP-complete.

## 2. Search versus Decision Problem (25 points)

Recall that $\text{3-SAT}$ is the following decision problem:

> *"Given a formula $\phi$ which is a conjunction of $k$ clauses over a set of variables $\{x_1, x_2, \dots, x_n\}$, does there exist a satisfying truth assignment for $\phi$?"*

Consider the analogous problem **3-SATSEARCH** that computes a satisfying assignment for $\phi$, if one exists, or outputs `"\phi is unsatisfiable"`, otherwise.

Show that if $\text{3-SAT}$ can be solved in polynomial time, then **3-SATSEARCH** can be solved in polynomial time.

### Hints
* **Hint 1:** Do this by providing an algorithm that solves **3-SATSEARCH** by doing calls to the polynomial-time algorithm that decides $\text{3-SAT}$. Justify that your algorithm runs in polynomial time.
* **Hint 2:** One can force the value of a variable $x_i$ in formula $\phi$, by transforming $\phi$ into $\phi \wedge \phi_{i,v}'$, where $\phi_{i,v}'$ uses two extra variables $y$ and $z$:
  * **Forcing $x_i = 1$:** 
    $$\phi_{i,1}' = (x_i \vee y \vee z) \wedge (x_i \vee y \vee \overline{z}) \wedge (x_i \vee \overline{y} \vee z) \wedge (x_i \vee \overline{y} \vee \overline{z})$$
  * **Forcing $x_i = 0$:** 
    $$\phi_{i,0}' = (\overline{x_i} \vee y \vee z) \wedge (\overline{x_i} \vee y \vee \overline{z}) \wedge (\overline{x_i} \vee \overline{y} \vee z) \wedge (\overline{x_i} \vee \overline{y} \vee \overline{z})$$

---

### Algorithm: `3-SatSearchALG`

```text
Algorithm 3-SatSearchALG(phi)
Input: A formula phi in conjunctive normal form with three literals per clause,
       having n variables and k clauses.
Output: A truth assignment to x_1, x_2, ..., x_n that satisfies phi,
        or "phi is not satisfiable"

if (3-SAT-ALG(phi) == 'no') then
    return "phi is not satisfiable"
else
    phi' <- phi
    for i = 1 to n do
        if (3-SAT-ALG(phi' AND phi'_{i,1}) == 'yes') then
            phi' <- phi' AND phi'_{i,1}
            x_i <- 1
        else
            phi' <- phi' AND phi'_{i,0}
            x_i <- 0
    return (x_1, x_2, ..., x_n)
```

### Justification of Polynomial Running Time

Assume `3-SAT-ALG` is a polynomial-time algorithm that solves $\text{3-SAT}$. The above algorithm repeats $n$ times the loop. The loop consists of a constant number of operations and a call to `3-SAT-ALG`, which runs in time polynomial with its input size. 

Over all the iterations, the input formula grows from $\phi$ (having $n$ variables and $k$ clauses) to a formula with $n+2$ variables and $k + 4n$ clauses. So each formula for which `3-SAT-ALG` is called has a size polynomial in the size of $\phi$. Therefore, each call to `3-SAT-ALG` runs in time polynomial in the size of $\phi$, and the overall algorithm runs in polynomial time.

## 4. CLIQUE is NP-Complete (25 points)

### Definitions
* An **independent set** in a graph $G=(V,E)$ is a subset $I \subseteq V$ such that for all $x, y \in I$, $\{x, y\} \notin E$.
* A **clique** in a graph $G'=(V',E')$ is a subset $C \subseteq V'$ such that for all $x, y \in C$ with $x \neq y$, $\{x, y\} \in E'$.
* The **complement** of a graph $G=(V,E)$ is a graph $\overline{G}=(V,E')$ such that for every $x, y \in V, x \neq y$, $\{x,y\} \in E'$ if and only if $\{x,y\} \notin E$.

---

### Part A (10 points)
Let $G=(V,E)$ be a graph, let $\overline{G}$ be its complement graph, and let $S \subseteq V$. Prove that $S$ is an independent set of $G$ if and only if $S$ is a clique of $\overline{G}$.

#### Proof:
* $(\Rightarrow)$ Let $S$ be an independent set of $G$. Then for all $x, y \in S$ ($x \neq y$), we have $\{x, y\} \notin E$. By definition of complement graph $\overline{G}$, this implies $\{x, y\} \in E'$. Therefore, $S$ is a clique in $\overline{G}$.
* $(\Leftarrow)$ Let $S$ be a clique of $\overline{G}$. Then for all $x, y \in S$ ($x \neq y$), we have $\{x, y\} \in E'$. By definition of complement graph $\overline{G}$, this implies $\{x, y\} \notin E$. Therefore, $S$ is an independent set in $G$.

---

### Part B (15 points)
Prove that **CLIQUE** is NP-complete.

#### 1. Prove that $\text{CLIQUE} \in \mathcal{NP}$ (5 points):
We can build an efficient certifier for $\text{CLIQUE}$, whose inputs are $(G, k)$ and a certificate consisting of a set of vertices $S$. 
* The certifier checks that $|S| \ge k$ and that for all $x, y \in S$ with $x \neq y$, $\{x, y\} \in E(G)$.
* The certificate contains at most $n$ vertex identifiers, so its size is polynomial in the input size $|(G,k)|$.
* Checking all pairs in $S$ takes $O(n^2)$ time, which is polynomial.

#### 2. Prove that $\text{CLIQUE}$ is NP-hard (10 points):
We reduce from $\text{INDEPENDENT-SET} \le_P \text{CLIQUE}$.

* **Reduction Algorithm:**
  1. Input: An instance $(G, k)$ of $\text{INDEPENDENT-SET}$.
  2. Compute the complement graph $\overline{G} = (V, E')$.
  3. Output: $(\overline{G}, k)$ as an instance of $\text{CLIQUE}$.

* **Polynomial Running Time:**
  Constructing $\overline{G}$ requires checking for each pair of distinct vertices $x, y \in V$ whether an edge exists in $G$ and adding/omitting the edge in $\overline{G}$. This takes $O(n^2)$ time, which is polynomial in the size of the input.

* **Correctness (Yes/No Instance Mapping):**
  * **If $(G, k)$ is a YES-instance:** There exists an independent set $S$ of size $k$ in $G$. By Part A, $S$ is a clique of size $k$ in $\overline{G}$, so $(\overline{G}, k)$ is a YES-instance for $\text{CLIQUE}$.
  * **If $(G, k)$ is a NO-instance:** There is no independent set of size $k$ in $G$. By Part A, there cannot exist a clique of size $k$ in $\overline{G}$, so $(\overline{G}, k)$ is a NO-instance for $\text{CLIQUE}$.
