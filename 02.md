## 1. Prove that $3\text{-SAT} \le_p \text{DOUBLE-SAT}$
**Statement:** Show $\text{DOUBLE-SAT}$ is NP-complete by reduction from $3\text{-SAT}$.

The $3\text{-SAT}$ problem consists of a conjunction of clauses over $n$ Boolean variables, where each clause is a disjunction of 3 literals, e.g.,
$$(x_{1}\vee\neg x_{3}\vee\neg x_{5})\wedge(x_{2}\vee x_{4}\vee\neg x_{6})\wedge(\neg x_{3}\vee\neg x_{5}\vee x_{6})$$

The $\text{DOUBLE-SAT}$ problem takes as input a Boolean formula $f$, and asks if there are two satisfying assignments for $f$.

### Solution:
$\text{DOUBLE-SAT}$, like any variant of $\text{SAT}$, is in $\text{NP}$ since the truth assignment is the certificate; we can check every clause in polynomial time to see if it is satisfied.

We now show a reduction from $3\text{-SAT}$. Given a $3\text{-SAT}$ formula $f$, we construct a $\text{DOUBLE-SAT}$ formula:
$$f' = f \wedge (x_{k} \vee \neg x_{k})$$
where $x_k$ is a variable not used in $f$. Clearly this reduction is poly-time.

We now show that $f$ has a satisfying assignment iff $f'$ has two satisfying assignments.

* **$(\Rightarrow)$** If $f$ has a satisfying assignment $\sigma$, then $f'$ has two satisfying assignments, corresponding to $(\sigma, x_{k} = \text{true})$ and $(\sigma, x_{k} = \text{false})$.

The clause $(x_k \vee \neg x_k)$ can be satisfied with either $x_k$ true or $x_k$ false. In either case, if we have a satisfying assignment $\sigma$ for $f$, this ensures $\text{DOUBLE-SAT}$ is validated. In this case, then $3\text{-SAT}$ is also validated.

## 2. Prove that $\text{Hamilton Cycle} \le_p \text{Directed-HC}$
**Statement:** Show $\text{Directed-HC}$ is NP-complete by reduction from $\text{Hamilton Cycle}$. The $\text{Hamilton Cycle}$ ($\text{HC}$) problem asks if there is a simple cycle that visits every node once in an undirected graph $G(V,E)$.

* **INSTANCE:** For $\text{Directed-HC}$ we are given as input a directed graph $G'(V,E')$.
* **QUESTION:** Is there a simple directed cycle that visits every node once?

### Solution:
We first must show that $\text{DHC}$ is in $\text{NP}$: Given a certificate (path in $G'$) we can check in poly-time if this is Hamiltonian.

We now demonstrate how to reduce $\text{HC}$ to $\text{DHC}$. Let $G=(V,E)$ be the input for $\text{HC}$. We create a $\text{DHC}$ graph $G'=(V,E')$ by a reduction operator $T$ that takes each edge in $G$ and replaces it by two edges in $E'$ (one going in each direction). (This is just the standard way in which an undirected graph is converted into a directed graph.) Clearly this reduction takes poly-time.

We now show that $\text{HC}$ has a yes answer iff $\text{DHC}$ has a yes answer.

* **$(\Rightarrow)$** Assume $G$ has a Hamilton circuit. By our construction, we must have a directed Hamilton circuit in $G'$.
* **$(\Leftarrow)$** Assume $G'$ has a directed Hamilton circuit. By our construction, we must have a Hamilton circuit in $G$.

$\text{NAE-3-SAT}$, like any variant of $\text{SAT}$, is in $\text{NP}$ since the truth assignment is the certificate; we can check every clause in polynomial time to see if it is satisfied.

It is easy to check that this works, i.e., by setting $w$ appropriately we can satisfy these two $\text{NAE-3-SAT}$ clauses unless $y_{i}=y_{j}=y_{k}=z$.

## 7. Prove that $\text{Vertex Cover} \le_p \text{Set Cover}$

### The Set Cover Problem:
* **INSTANCE:** A set $X=\{x_{1}, x_{2}, \dots, x_{n}\}$ and a collection $S=\{S_{1}, S_{2}, \dots, S_{m}\}$ of subsets of $X$ such that $S$ covers $X$, i.e., $S_{1}\cup S_{2}\cup \dots \cup S_{m}=X$. A cover set is any sub-collection $C\subseteq S$ that also covers $X$.
* **QUESTION:** Given $(X, S, K)$, is there a cover set $C$ of size $\le K$?

### Solution:
First, we argue that $\text{Set Cover}$ is in $\text{NP}$, since given a collection of sets $C$, a certifier can efficiently check that $C$ indeed contains at most $k$ elements, and that the union of all sets listed in $C$ does include all elements from the ground set $X$.

We will now show that $\text{Vertex Cover} \le_p \text{Set Cover}$. Given an instance of $\text{Vertex Cover}$ (i.e., a graph $G=(V,E)$ and an integer $j$), we will construct an instance of the $\text{Set Cover}$ problem:

1. Let $X = E$.
2. We will define $n$ subsets of $X$ as follows: label the vertices of $G$ from $1$ to $n$, and let $S_i$ be the set of edges incident to vertex $i$ (the edges for which vertex $i$ is an end-point). Note that $S_i \subseteq X$ for all $i$.
3. Finally, let $k = j$.

This construction can be done in time that is polynomial in the size of the $\text{Vertex Cover}$ instance. We now run our black box for the $\text{Set Cover}$ problem and return the same result it gives.

To prove that this answer is correct, we simply need to show that the original instance of $\text{Vertex Cover}$ is a yes instance if and only if the $\text{Set Cover}$ instance we created is also a yes instance.

* **$(\Rightarrow)$** Suppose $G$ has a vertex cover of size at most $j$. Let $S$ be such a set of nodes. By our construction, $S$ corresponds to a collection $C$ of subsets of $X$. Since we defined $k=j$, $C$ clearly has at most $k$ subsets. Furthermore, we claim that the sets listed in $C$ cover $X$. To see this, consider any element of $X$. Such an element is an edge $e$ in $G$, and since $S$ is a vertex cover for $G$, at least one of $e$'s endpoints is in $S$. Therefore, $C$ contains at least one of the sets associated with the endpoints of $e$, and by definition, these both contain $e$.

* **$(\Leftarrow)$** Now suppose there is a set cover $C$ of size $k$ in our constructed instance. Since each set in $C$ is naturally associated with a vertex in $G$, let $S$ be the set of these vertices. $|S|=|C|$ and thus $S$ contains at most $j$ nodes. Furthermore, consider any edge $e$. Since $e$ is in the ground set $X$ and $C$ is a set cover, $C$ must contain at least one set that includes $e$. But by our construction, the only sets that include $e$ correspond to nodes that are endpoints of $e$. Thus, $S$ must contain at least one of the endpoints of $e$.

We have now shown that our algorithm solves the $\text{Vertex Cover}$ problem using a black box for the $\text{Set Cover}$ problem. Since our construction takes polynomial time, and we have shown that $\text{Set Cover}$ is in $\text{NP}$, we can conclude that $\text{Set Cover}$ is NP-Complete.

## 8. Prove that $\text{Hamiltonian Cycle} \le_p \text{TSP}$

### The Traveling Salesman Problem:
* **INSTANCE:** An $n \times n$ weighted adjacency matrix $D=(d_{ij})$ of a complete weighted graph on $n$ vertices with integer edge lengths $d_{ij}$, and an integer $K$.
* **FEASIBLE SOL:** A $\text{TSP}$ tour is any Hamiltonian cycle in this complete graph.
* **QUESTION:** Is there a $\text{TSP}$ tour of length (or distance) $\le K$?

### Solution:
1. It is simple to show that $\text{TSP} \in \text{NP}$. Given a certificate for $\text{TSP}$, we can show it is correct or not in time $O(|V|^2)$ (or $O(|E|^2)$).
2. The reduction is as follows: We assume we are input a $\text{Hamiltonian Cycle}$ instance of a graph $G(V,E)$ and must construct a $\text{TSP}$ instance $G'(V',E')$ together with a weight function $w(E')$.

Given a graph $G$ with $n$ vertices, construct a new weighted complete graph $G'$ with the same vertices ($V' = V$) and we add edges $E^*$ such that $E' = E \cup E^*$. We create the weight function such that:
$$w(u, v) = \begin{cases} 1 & \text{if } (u,v) \in E \\ 2 & \text{if } (u,v) \notin E \end{cases}$$

Clearly, this reduction can be done in time polynomial in $G(V,E)$.

We claim that $G$ has a Hamilton Cycle iff there is a Hamilton Cycle in $G'$ with a total weight of $n$.

* **$(\Rightarrow)$** Suppose $G$ has a Hamilton Cycle; by our construction this must mean that $G'$ has a TSP tour of cost $n$.
* **$(\Leftarrow)$** Now suppose that $G'$ has a TSP tour of cost $n$. By our construction this must mean that $G$ has a Hamilton Cycle, since only edges in $G$ have cost 1 in $G'$.

The $\text{Hamilton Cycle}$ problem reduces to the $\text{Traveling Salesman Problem}$, therefore the $\text{Traveling Salesman Problem}$ is NP-hard. Since $\text{TSP}$ is also in $\text{NP}$, we have thus shown it is NP-complete.

* **QUESTION:** Is there a $\text{TSP}$ tour of length (or distance) $\le K$?

### Solution:

1. It is simple to show that $\text{TSP} \in \text{NP}$. Given a certificate for $\text{TSP}$, we can show it is correct or not in time $O(\vert{}V\vert{}^2)$ (or $O(\vert{}E\vert{}^2)$).
2. The reduction is as follows: We assume we are input a $\text{Hamiltonian Cycle}$ instance of a graph $G(V,E)$ and must construct a $\text{TSP}$ instance $G'(V',E')$ together with a weight function $w(E')$.

Given a graph $G$ with $n$ vertices, construct a new weighted complete graph $G'$ with the same vertices ($V' = V$) and we add edges $E^*$ such that $E' = E \cup E^*$. We create the weight function such that:


$$w(u, v) = \begin{cases} 1 & \text{if } (u,v) \in E \\ 2 & \text{if } (u,v) \notin E \end{cases}$$

Clearly, this reduction can be done in time polynomial in $G(V,E)$.

We claim that $G$ has a Hamilton Cycle iff there is a Hamilton Cycle in $G'$ with a total weight of $n$.

* **$(\Rightarrow)$** Suppose $G$ has a Hamilton Cycle; by our construction this must mean that $G'$ has a TSP tour of cost $n$.
* **$(\Leftarrow)$** Now suppose that $G'$ has a TSP tour of cost $n$. By our construction this must mean that $G$ has a Hamilton Cycle, since only edges in $G$ have cost 1 in $G'$.

The $\text{Hamilton Cycle}$ problem reduces to the $\text{Traveling Salesman Problem}$, therefore the $\text{Traveling Salesman Problem}$ is NP-hard. Since $\text{TSP}$ is also in $\text{NP}$, we have thus shown it is NP-complete.
